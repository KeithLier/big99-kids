# 🏰 萌娃智慧成长乐园 (kids-study) — 幼小衔接与少儿启蒙全能版 v3.0

> 一款基于 **Vue 3 + Vite + Vue Router** 构建的现代化儿童幼小衔接启蒙与中小学学习闯关平台。  
> 集成了 **「🔤 汉语拼音启蒙乐园」**、**「🌈 快乐英语启蒙乐园（含亲子情景沟通剧场）」**、**「📜 中华古诗词趣味画卷（小学 / 初中 / 高中分级）」** 与 **「🎠 19×19 大九九乘法口诀闯关乐园」** 四大王牌模块，并配备全站通用的**田字格手写签名档案、跨学科智慧星章与萌宠贴纸激励系统**，支持一键部署至 **Vercel**。

---

## 🌟 核心功能与架构亮点

### 1. 🏠 现代化童趣首页（全科成长中心 `/`）
- **小主人专属成长名片**：支持在田字格画板上手写签名、选择萌宠头像，跨学科（拼音 + 英语 + 古诗词 + 乘法）累计「✨ 智慧值」与头衔晋升（从「🌱 萌娃智慧小萌新」进阶至「👑 博古通今大状元」）。
- **四大王牌课程卡片**：一键直达「汉语拼音启蒙乐园」、「快乐英语启蒙乐园」、「中华古诗词趣味画卷」或「19×19 大九九乘法闯关乐园」。
- **今日推荐古诗 & 全站萌宠贴纸册**：每日随机推荐经典诗词，支持首页即点即读；学习拼音、英语、古诗与乘法均可攒智慧值解锁 10 只超萌神兽贴纸（🐣 ➔ 🐶 ➔ 🐱 ➔ 🐼 ➔ 🦊 ➔ 🐰 ➔ 🦁 ➔ 🦖 ➔ 🦄 ➔ 🐉）。

### 2. 🔤 汉语拼音启蒙乐园（幼小衔接核心课 `/pinyin`）
- **63 个拼音精灵全收录**：
  - **📢 声母表 (23个)**：`b p m f d t n l g k h j q x zh ch sh r z c s y w`
  - **🎵 韵母表 (24个)**：涵盖单韵母 (6个)、复韵母 (9个)、前鼻韵母 (5个)、后鼻韵母 (4个)
  - **🚀 整体认读音节 (16个)**：`zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying`
- **📏 标准四线三格互动黑板 & 拍手顺口溜**：
  - 直观展示每个拼音字母在四线三格中的标准占格位置；
  - 配备形象记忆**拍手顺口溜**（如“右下半圆 b b b，拉开天线听广播”）、**发音口型小窍门**与**代表词语点读**；
  - 针对中文 TTS 专门优化声母/韵母呼读音（如 `b` 准确发“播”音，绝不误读为英文字母）。
- **🚂 四声调过山车小火车（动态 SVG 声调轨道）**：
  - 将抽象的四声调转化为可视化 SVG 过山车轨道：**一声平（ˉ）彩虹桥、二声扬（ˊ）爬山坡、三声拐弯（ˇ）过山谷、四声降（ˋ）滑滑梯**，小火车随点击动态行驶并朗读四声调组词。
- **🧪 魔法拼读实验室（两拼 & 三拼音节合成器）**：
  - 自由体验「声母 + (介母) + 韵母 + 声调帽 = 汉字与例句」的积木碰撞过程，掌握“前音轻短后音重”与“声轻介快韵母响”拼读规则。
- **🎮 3 大拼音趣味闯关游戏**：
  - **👂 游戏 1：听音捉迷藏**：听顺口溜与发音，从气泡中抓出正确的拼音精灵。
  - **🚂 游戏 2：声调小火车**：看图看字，帮小火车选出正确的声调帽子。
  - **🧩 游戏 3：拼音积木大拼图**：看图识字，按顺序点击声母、介母、韵母积木拼出完整音节。

### 3. 🌈 快乐英语启蒙乐园（亲子双向沟通 `/english`）
- **🅰️ 26 字母魔法屋（Aa ~ Zz 自然拼读）**：
  - 标准英语四线三格展示大小写 `Aa ~ Zz`，配有**自然拼读韵律口诀**（如 `A is for Apple, a-a-apple`）、国际音标、自然拼读音及代表单词例句。
- **🍎 8 大日常主题单词百宝箱**：
  - 涵盖 **🐾 萌宠动物、🍎 水果美食、🎨 缤纷颜色、🔢 趣味数字、👨‍👩‍👧 温暖家人、🎒 小学生文具、🌈 天气与自然、🚗 交通工具** 共 56 个高频启蒙单词，支持正常/慢速双语例句点读。
- **👨‍👩‍👧 亲子双角色情景沟通剧场（核心亮点：爸妈 & 宝贝互动对练）**：
  - 精选 **6 大高频亲子生活场景**：
    1. `🌅 早晨起床问候 (Happy Morning Routine)`
    2. `🍽️ 快乐用餐时光 (Yummy Mealtime)`
    3. `🛒 超市购物小帮手 (Supermarket Helper)`
    4. `🦒 动物园奇妙游 (At the Animal Zoo)`
    5. `🤝 社交礼仪：认识新朋友 (Making New Friends)`
    6. `🌙 温馨睡前晚安 (Sweet Bedtime)`
  - **贴心亲子共学功能**：内置**「💡 家长引导锦囊」**、**「🎭 一键互换角色」**、**「🐢 慢速逐词点读拆解」**、**「▶️ 全剧自动连播示范」**，演练完毕后点击「🙌 击掌打卡 (High Five)」即可赢取智慧值与金星！
- **🎪 3 大英语趣味闯关游戏**：
  - **🎈 游戏 1：字母大小写找朋友**：帮大写字母妈妈找到对应的小写字母宝宝。
  - **🔊 游戏 2：听音摘果子**：听纯正英文发音，选出对应的趣味图案卡片。
  - **💬 游戏 3：亲子情景交际小达人**：爸爸妈妈用英语提问，宝贝选出最得体有礼貌的英文回答。

### 4. 📜 中华古诗词趣味画卷（小学 · 初中 · 高中分级 `/poetry`）
- 支持按学段（小学/初中/高中）、年级、朝代与 8 大动态意境画风筛选；支持全诗配乐感连读、遮字盲背、深度背景解析以及「点字成诗、飞花令接龙、填字小侦探、智慧问答」4 大游戏。

### 5. 🎠 19×19 大九九乘法口诀表（独立算术乐园 `/big99`）
- 包含 19×19 科学分级色块海报、小学常用单位换算速查表（点击发音）、6岁小九九放大模式、三步通关法（小鹦鹉跟读 + 喂恐龙/打地鼠/射气球/盖印章 4 大游乐场 + 数字怪兽决战）以及怪兽偷袭复习守卫战。

### 6. ⚙️ 全站声音与音色设置中心（更换试听浏览器内置声音 & 录入一段话用个人音色播放全部音频 `/voice-settings`）
- **🔊 纯中文男女声过滤与自由切换**：
  - 自动扫描并严格过滤出设备/浏览器中**100% 真正可用出声的中文男声与女声**，彻底剔除不可用的英文与外语发音人；
  - 声音分类明确支持**「👩 中文女声」**与**「👨 中文男声」**一键筛选，提供古诗、拼音、九九乘法口诀及夸奖金句专属快捷试听；
  - 每张中文声音卡片均支持**「▶️ 试听声音」**与**「✨ 选择使用此声音」**，一键设为全站默认发音人；
  - 内置**全局朗读语速 (`0.55x ~ 1.4x`)** 与 **全局声音音调 (`0.6 ~ 1.5`)** 实时调节滑块。
- **🎙️ 悬浮录音按钮控制**：
  - 悬浮声音按钮默认重构为仅 48px 的小巧圆形 `🎙️` 图标，不遮挡学习界面；
  - 在声音工坊提供专属开关，支持用户彻底隐藏右下角悬浮录音球。
- **🎙️ 录入我的一段话 · 用我的音色播放全站所有音频**：
  - 无需逐句录制几百个词条！只需在设置页录入一段 **5~15 秒**的话，系统通过 **Web Audio API 时域自相关声纹分析算法**自动提取您的平均基频 (`Hz`)、声线冷暖与语速特征，生成个人声纹音色档案；
  - 支持**「⚡ 本地声纹智能拟真（免 API Key 开箱即用）」**与**「🤖 AI 零样本高保真声音克隆（接入硅基流动 `FunAudioLLM/CosyVoice2-0.5B` 1:1 复刻真实嗓音）」**双引擎，开启后全站所有拼音、英语、古诗词、乘法音频均使用您录入的音色播放！
- **🎤 逐句真人配音工坊**：
  - 支持爸爸、妈妈、宝贝按分类逐句录制 100% 原声录音，并支持一键导出/导入 `.json` 全套声音设置与录音备份包。

### 7. 📱 iPad 与小屏极致空间优化（顶部精简与沉浸学习）

## 🚀 本地开发与 Vercel 部署

### 1. 本地运行

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 2. 一键部署至 Vercel

项目根目录已配置好 `vercel.json`（含 SPA History 路由重写规则），可直接通过 Git 推送或使用 Vercel CLI 部署：

```bash
vercel --prod
```
