# 🎠 大九九乘法口诀表 - 6岁萌娃趣味闯关乐园 (big99-kids)

> 一款专为 6 岁+ 儿童及小学低年级量身定制的 **19×19 大九九乘法口诀趣味学习与闯关 Web 应用**。  
> 融合「经典海报视觉」+「科学色块记忆规律」+「单位换算速查」+「三步趣味通关游戏」，深度适配 iPad 触控与大屏体验。

---

## 🌟 项目亮点与设计理念

传统大九九乘法表（1×1 到 19×19，共 190 个算式）信息量大、背诵枯燥，容易让低龄儿童产生畏难情绪。本项目立足儿童认知心理学与第一性原理，将传统严肃的挂图改造为兼具美感与趣味的数字化游乐园：

1. **科学分级色块与规律引导**
   - **🟨 小九九区域（1~9乘法）**：小学必备基础，巩固低年级基本功。
   - **🩷 有规律背（11、19、9、对角平方数等）**：引导孩子发现数字对称美与速算规律。
   - **🟩 尽量背（2~8 与两位数乘法）**：大九九核心进阶区，采用形象化拆十法辅助。
   - **默认掌握（乘1、乘10）**：秒杀题型，建立满满自信。
   - **🔴 红色高亮字体（平方数，熟记于心）**：12×12=144、15×15=225、19×19=361 等速算基石。
   - **🔵 蓝色高亮字体（高频数，滚瓜烂熟）**：如 15×2=30、16×5=80 等奥数与速算常客。

2. **完整内置小学常用单位换算表**
   - 充分利用 19×19 阶梯上方的空白空间，精心布局 **长度、面积、体(容)积、重量、人民币、时间（含大月/小月/平年/闰年）** 等核心单位换算。
   - 支持**全条目点击中文语音朗读**，看表、查表、听读三合一。

3. **专为 6 岁儿童设计的「三步通关法」**
   - **第 1 步：🦜 鹦鹉趣味跟读**  
     大字号口诀展示，标准普通话语音领读；配备“一眼看懂点阵图”与“拆十小魔法”，用盘子装草莓、甜甜圈具象拆解乘法乘积。
   - **第 2 步：🎮 4 大游乐场交互小游戏**  
     - 🦖 **贪吃小恐龙**：给小恐龙分组喂食，理解“几个几”。
     - 🕳️ **乘法打地鼠**：快速敲击正确得数，锻炼口算反应力。
     - 🎈 **气球嘉年华射手**：点击射爆目标数字气球。
     - 🍓 **彩虹印章垫**：逐行加盖水果印章，数出乘法矩阵。
   - **第 3 步：⚔️ 小骑士 vs 数字怪兽决战**  
     三道递进式挑战（口诀正向、因数逆算、图文情境题），扣减怪兽爱心血量；全胜触发满屏**五彩纸屑庆祝（Confetti）**与胜利号角！

4. **萌娃手写签名画板与专属成长档案**
   - 首次进入乐园提供专属**手写签名画板（Name Pad Canvas）**，支持用手指或 Apple Pencil 手写签名并选择萌宠头像。
   - 所有闯关奖状与成就页面均印有宝贝的真实手写笔迹，仪式感满满。

5. **🚨 怪兽偷袭复习·记忆守卫战（防假性记忆）**
   - 依据艾宾浩斯遗忘曲线设计：怪兽会随机“偷袭”已学方格！
   - 进入无提示盲算突击问答，守卫成功即可将方格升级为最高荣誉 **⭐ 璀璨大金星**。

6. **🙈 盲算自测遮罩模式**
   - 一键开启「遮挡得数」，全表积数智能隐藏，仅保留算式因数；
   - 方便家长随堂考查，也便于孩子自主背诵检验。

7. **萌宠贴纸册与阶梯激励体系**
   - 包含智能推荐下一格（`🪜 推荐下一格`），科学规划学习路线；
   - 随累计通关数量逐步解锁 **10 种萌宠贴纸**（🐣 萌鸡 ➔ 🐶 狗狗 ➔ 🐱 猫咪 ➔ 🐼 熊猫 ➔ 🦊 小狐狸 ➔ 🐰 兔子 ➔ 🦁 狮子 ➔ 🦖 恐龙 ➔ 🦄 独角兽 ➔ 🐉 神龙）；
   - 从「🌱 乘法小萌新」一步步进阶为「👑 大九九大满贯宗师」！
   - 内置成长成就勋章系统，数据全部通过 `LocalStorage` 离线留存。

8. **纯原生零依赖架构（Zero-Dependency）**
   - 单文件 HTML5 架构（包含内联 CSS、Canvas 与 JS），无须安装庞大的 node_modules，双击即可在任何现代浏览器中飞速打开。
   - 内置通过 Web Audio API 动态合成的轻快音效，无需外链加载音频资源，离线完全可用。

## 📱 iPad 与设备适配

针对儿童高频使用的 iPad 和触控平板进行了专门适配：

- **自适应缩放（Auto-Fit Scaler）**：iPad 横屏放置时可完整纵览整张大九九海报。
- **双视图模式切换**：
  - `🔍 适屏全览`：整表一览无遗，全局掌握学习进度。
  - `🖐️ 大格滑动模式`：方格放大显示，适合小手精准触控点击。
- **iOS/iPadOS 音频激活**：首触即解锁 Web Audio 与 SpeechSynthesis，朗读流畅不中断。

## 🚀 快速开始

### 方式一：直接在浏览器中打开（最简易）

直接双击项目中的 [index.html](file:///Users/keith/Desktop/big99-kids/index.html) 文件，或右键选择 Chrome / Safari / Edge 浏览器打开即可。

### 方式二：通过本地 HTTP 服务运行

如果你需要在同一局域网下的 iPad / 平板上访问：

```bash
# 进入项目目录
cd /Users/keith/Desktop/big99-kids

# 使用 Python 启动简易静态服务器
python3 -m http.server 8080

# 或使用 Node.js 的 npx serve
npx serve .
```

启动后，在同一 Wi-Fi 下的 iPad 浏览器中输入 `http://<你的电脑IP>:8080` 即可开始使用。

### 方式三：一键部署到云端

项目根目录下已配置好 Vercel 静态支持：
- 使用 [Vercel CLI](https://vercel.com/docs/cli)：在根目录下执行 `vercel`。
- 或直接将代码推送到 GitHub，并在 Vercel / GitHub Pages 控制台绑定该仓库，开箱即用。

## 🛠️ 技术实现细节

| 模块 | 技术方案 | 优势 |
| :--- | :--- | :--- |
| **界面排版** | CSS Grid (19×19) + Flexbox | 乘法表与单位换算卡片零重叠、严格对齐 |
| **交互动画** | CSS3 Keyframes + Canvas 2D | 流畅 60fps 动效，打怪撒花效果极佳 |
| **音效系统** | 原生 Web Audio API (OscillatorNode) | 纯代码合成咀嚼、敲击、通关号角，无网络开销 |
| **口诀朗读** | 原生 Web Speech API (zh-CN) | 离线自然发音，无需第三方付费 TTS 接口 |
| **进度存储** | 原生 `window.localStorage` | 纯客户端离线留存，尊重隐私、安全轻量 |

## 💡 使用小贴士

1. **随机抽题练习**：点击顶部工具栏的 `🎲 随机抽一格玩`，系统会自动从未通关的方格中随机挑选题目。
2. **分类集中强化**：点击顶部或右下角图例按钮（如“小九九”、“平方数”、“滚瓜烂熟”），整张表会自动聚焦高亮目标分类。
3. **重新开始打卡**：点击顶部 `重置` 按钮并确认，即可重置通关记录与贴纸册，开始新一轮挑战。
