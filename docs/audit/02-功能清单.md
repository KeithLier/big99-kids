## 核心业务流

### 1. 学习档案与全站成长

`src/App.vue:43-49,79-80` 点击档案 → `src/components/SignatureModal.vue:282-304` 校验昵称/签名并生成图片 → `src/composables/useKidsProfile.js:84-91` 更新共享档案与 `localStorage` → 学科页面调用各自的 `record*Progress`（`:124,173,191,211`）→ `totalWisdomPoints` 汇总（`:267-282`）→ 首页消费档案及统计（`src/views/HomeView.vue:381-404`）。后端接口：无，静态链路末端为浏览器本地存储。

### 2. 拼音选择与答题

`/pinyin` → `src/views/PinyinView.vue:735-754` 选卡 → `recordPinyinProgress`（`src/composables/useKidsProfile.js:173-187`）写学习记录；并由 `speakText` 朗读 → `src/composables/useSound.js:276-289` 按设置选择录音/可选 AI → `src/composables/useVoiceStudio.js:813-853` 的可选合成接口。答对听音题会追加星数（`src/views/PinyinView.vue:1028-1035`）。拼音内容来自 `src/data/pinyinData.js`（页面 `:661-670`）。

### 3. 古诗筛选、详情、朗读

`/poetry` → `src/views/PoetryListView.vue:270-307` 筛选并跳转 `/poetry/:id` → `src/views/PoetryDetailView.vue:494-511` 按 id 调用 `src/data/index.js:15-16` 取本地诗词 → 朗读结束回调调用 `recordPoetryProgress`（`PoetryDetailView.vue:540-550`）→ `src/composables/useKidsProfile.js:124-146` 记录本地进度；朗读可选走上述语音服务。非法 id 静态逻辑会回退第一首诗（`src/data/index.js:15-16`），预期【待确认】。

### 4. 全国地图到城市百科

`/geography` → `src/views/ChinaGeoView.vue:507-512` 加载 `public/geo/100000.json` → 点击省份调用 `goToProvince`，记录省份并跳转（`:521-535`）→ `src/views/GeoProvinceView.vue:615-639` 初始化、读取 `public/geo/${adcode}.json`（`:535-541`）→ 选城市（`:549-559`）→ `recordGeoProgress` 将省市记录写本地（`src/composables/useKidsProfile.js:211-225`）。城市介绍取 `src/data/chinaGeoData.js`（`GeoProvinceView.vue:349`），可朗读（`:580-600`）。地图 JSON 是静态资源，不是后端业务 API；页面无中间业务组件证据。

### 5. 录音、保存及可选克隆

`/voice-studio` → `src/views/VoiceStudioView.vue:1067-1096` 启动并停止录音 → `src/composables/useVoiceStudio.js:891-918,927-944` 调用 `getUserMedia` 与 `MediaRecorder` → `saveVoiceClip` 写 IndexedDB（`:687-707`）。可选上传链：`src/views/VoiceStudioView.vue:954-966` → `uploadReferenceVoiceToSiliconFlow` → `POST /v1/uploads/audio/voice`（`src/composables/useVoiceStudio.js:856-879`）；后续可选合成走 `POST /v1/audio/speech` 或用户配置地址（`:813-839`）。麦克风权限、外部服务返回及语音实际质量【待确认】，需在授权环境手工验证。
