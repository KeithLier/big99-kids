## 决策比较

**选择渐进式重构**的量化依据：

- 现有规模为 **26 个源码文件、30,035 行**，有 9 个可识别页面入口（[测绘](00-项目测绘.md)、`src/router/index.js:10-65`）；现有单包、路由和数据集可作为迁移边界，功能并非必须同时替换。
- **12/12 个 Vue 文件超过 300 行**，最大 4,014 行；大九九的一个挂载回调达 2,212 行（[工程质量](03-工程质量.md)）。这说明局部改造有明确切口，但物理行数不能替代圈复杂度；真实耦合度和全仓循环依赖数【待确认】。
- 本仓库中未见测试文件、测试命令和覆盖率配置；核心逻辑覆盖率【待确认】，不能写成 0%。先建立回归保护，才有依据评估迁移是否保留行为（`package.json:7-10`）。
- 4 个直接依赖、2 个受影响包条目，以及已确认的 Key 导出和 HTML 注入路径，均可按模块处置（[工程质量](03-工程质量.md)、[风险专项](04-风险专项.md)）。
- 当前工作区的隔离安装和构建成功；Node 版本不满足依赖声明，不能将此次结果当成生产可靠性证明（[风险专项](04-风险专项.md)）。

**继续维护而不重构**的风险：双份存储、缺少可见回归测试和大回调会继续扩大修改范围；证据是 `src/views/Big99View.vue:238-258,234-2445` 与 `src/composables/useKidsProfile.js:11-23`。若产品未来基本不变、且可接受上述风险，最小安全修复后继续维护也可能成本更低；实际需求频率【待确认】。

**立即重写**的风险：需同时复刻 9 个页面、学科数据、本地进度、签名及声音备份（`src/router/index.js:10-65`、`src/composables/useKidsProfile.js:3-9`、`src/composables/useVoiceStudio.js:950-1008`），当前没有可见自动化行为基线，容易遗漏旧数据兼容与细节。重写收益、团队成本、真实用户量和业务未来变化【待确认】；仅凭现有证据无法证明重写更优。若后续发现核心契约不可保留或迁移成本持续超过重写估算，应重新比较。

目标：关闭已证实的凭据暴露路径与动态 HTML 注入面，限定开发工具暴露，建立可运行的基础回归。涉及 `src/views/Big99View.vue`、`src/components/SignatureModal.vue`、`src/composables/useVoiceStudio.js`、`src/views/VoiceStudioView.vue`、`package.json`、锁文件及 CI/测试配置。

### 第 2 批：结构改善（1–2 月，P1/P2）

目标：统一学习进度数据边界，拆出地图读取和错误反馈，清理已证实的生命周期问题。涉及 `src/composables/useKidsProfile.js`、`src/views/Big99View.vue`、`src/views/ChinaGeoView.vue`、`src/views/GeoProvinceView.vue`、`src/main.js` 和新增的服务/测试文件。

## 暂不建议做的事

- **不建议立即重写全部页面或更换 Vue 框架。** 9 个路由可分段迁移，重写需要同时保留本地进度和声音备份契约；未有业务需求、成本和自动化基线证明其 ROI 高（`src/router/index.js:10-65`、`src/composables/useVoiceStudio.js:950-1008`）。
- **不建议只因 12 个文件超 300 行就机械拆分所有页面。** 行数包含模板、样式和数据；先处理 2,212 行挂载回调、双份存储等有具体影响的边界，其他文件依据改动频率和测试成本决定（`src/views/Big99View.vue:234-2445`）。
- **不建议为满足形式指标一次性迁移全部代码到 TypeScript、引入全局状态库或虚拟化所有列表。** 当前未测得类型错误率、大列表卡顿或状态库迁移收益；先对服务/存储契约和实测瓶颈做小范围验证（`src/composables/useKidsProfile.js:11-23`、`src/views/PoetryListView.vue:270-292`）。
- **不建议未测量就追逐包体积数字。** 构建尺寸仅代表隔离产物，未测真实 LCP、缓存和网络；先建立基线再决定是否拆分（[风险专项](04-风险专项.md)）。
