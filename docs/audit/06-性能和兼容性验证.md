## 本机生产预览

使用 Node 22.22.1 执行 `npm run build -- --outDir /private/tmp/kids-study-bench-20261106 --emptyOutDir`，Vite 8.3.6 完成 70 个模块的构建。构建输出的首页入口 JS 为 308.10 kB、gzip 122.63 kB，入口 CSS 为 30.39 kB、gzip 6.40 kB；这是构建工具输出的资源尺寸，不包括 HTML、后续路由、地图请求、缓存和真实网络协议开销，也不是 LCP。

在本机浏览器的 localhost 生产预览中，打开大九九并完成 `1×1` 跟读、喂食、三轮答题；页面显示闯关成功，随后首页显示 `1/190` 和智慧值 1。浏览器环境未提供可读取的 Performance API，本次没有获得 LCP、INP、CLS 或带宽限速指标。

## 可重复采集步骤

1. 在待测环境使用 `.nvmrc` 指定的 Node 版本执行 `npm ci`、`npm run build`，再运行 `npm run preview -- --host 127.0.0.1`。真机跨设备访问需使用隔离测试网络和可达地址；不要将开发服务暴露到公共网络。
2. 对目标浏览器记录设备型号、系统/浏览器版本、网络条件、缓存状态和构建版本。至少分别测量冷缓存和热缓存，连续测量 5 次；记录首页 LCP、CLS、INP（有真实交互时）、首屏请求传输字节及样本值和中位数。
3. 测试大九九完成与跨页面进度、地图切换及慢网失败重试、声音失败降级；遇到错误仅保留错误类别，勿收集用户昵称、密钥、录音或其他个人数据。
4. 将基线和业务可接受值共同确定后，再对比同设备、同网络、同缓存条件下的前后版本；仅对实测瓶颈做延迟加载或虚拟化。当前没有真实设备数据，不能给出达标结论或声称优化了 LCP。
